EXPERIMENTO GUIADO / CIRCUITO RC

Carga y descarga de un capacitor

Explora cómo cambia el voltaje de un capacitor cuando se carga y cuando se descarga a través de una resistencia.

01

02

Tiempo 0.00 s

03

Instrucciones del experimento RC

  1. Define los valores de resistencia, capacitancia y voltaje de la fuente.
  2. Presiona Cargar para observar cómo aumenta el voltaje del capacitor.
  3. Presiona Descargar para observar cómo disminuye el voltaje almacenado.
  4. Compara las curvas y modifica R o C para analizar el efecto sobre la constante de tiempo.
  5. Usa Reiniciar para comenzar nuevamente el experimento.

En un circuito RC ideal, la constante de tiempo es τ = RC. Durante la carga, el voltaje del capacitor tiende al de la fuente; durante la descarga, tiende a cero.
